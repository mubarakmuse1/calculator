# Modern Calculator

A simple, modern calculator built using **HTML, CSS, and JavaScript**.

### Features
- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Decimal point support for decimal calculations.
- Safe division-by-zero error handling.
- Previous calculation displayed above the current result.
- Clear button to reset the calculator.
- Modern, responsive design with interactive buttons.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### How to Use
1. Open the calculator in your browser.
2. Enter numbers using the buttons.
3. Select an arithmetic operator.
4. Enter the next number.
5. Press `=` to see the result.
6. Press `C` to clear the calculator.
